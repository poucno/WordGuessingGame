# Guessing Garden

A kid-friendly Godot guessing game where players read a question and type the answer.

## How to play

1. Open the project in Godot 4.7 or newer.
2. Run the project.
3. Type an answer and press **Check answer** (or press Enter).
4. After three incorrect attempts, a hint appears.
5. Use **Play again** to restart and try for a higher score.
